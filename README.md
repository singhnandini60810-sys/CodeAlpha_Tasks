#How to Use

Quick "Spot the Phish" Checklist
Is the sender's address exactly the official domain, not a look-alike?
Does the message create urgency or threaten consequences?
Does it ask for passwords, OTPs or payment details?
Does the link's real destination (hover over it) match the claimed site?
Are there spelling errors, odd greetings or unexpected attachments?
Still unsure? Contact the organisation using a number or website you already trust.
